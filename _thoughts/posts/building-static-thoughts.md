# Building Static Thoughts

This site turns Markdown files into **plain static HTML** during build.

- Write post source in `_thoughts/posts/`
- Run `npm run build`
- Commit generated files

Read [Thoughts authoring notes](/THOUGHTS.md) for post format.

> No browser framework runtime is needed for these pages.
